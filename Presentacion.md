## 📌 Proyecto destacado

### 🏪 Servia — Sistema de gestión para restaurantes

Proyecto orientado a desarrollar una solución web tipo **POS/SaaS para restaurantes**, enfocada en simplificar la gestión de pedidos, mesas, domicilios, inventario, caja y facturación.

**Tecnologías y conceptos:**

-   Java
-   Spring Boot
-   REST API
-   MySQL / PostgreSQL
-   JWT
-   MapStruct
-   DTOs
-   JPA / Hibernate
-   Arquitectura por capas
-   POO
-   Autenticación y autorización

El proyecto busca solucionar problemas observados directamente en el funcionamiento de restaurantes, especialmente en la gestión de pedidos entre meseros, cocina y caja.
